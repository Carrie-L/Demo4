## Android 设备操作

每组独立用例前用开发面板清空状态。开关、间隔和测试时间仅用于验证，不能迁移到正式 UI。

| 操作 | 期望 |
|---|---|
| 冷启动不修改云配；完成首页搜索再返回 | 不弹，记录 HOME_SEARCH |
| 开启云配后返回首页 | 无需重做搜索即可弹 A |
| 首页搜索框 → 激活页 → 返回 | 不记录搜索，不弹 |
| 首页普通资讯 → 详情 → 激活页 → 结果 → 返回 | 不记录搜索 |
| 首页 → 激活 → 其他页 → 结果 → 返回 | 不记录搜索 |
| 首页 → 激活 → 结果 → 其他页 N 次 → 返回 | 弹 A |
| 首页搜索按钮 → 结果 → 返回 | 弹 A |
| 我的 → 书签/历史/下载 → 返回 | 弹 A；同一套 A 次数 |
| 只完成首页搜索，先回我的 | 不因首页行为在我的弹 A |
| AI 频道 → 详情 → 返回 AI 频道 | 弹 B |
| AI 行为完成，切推荐 | 不在推荐弹 B |
| A 展示当天，再触发 B | 不弹 B，保留 AI 行为 |
| 测试时间前进 24h，返回 AI 频道 | B 可弹，无需新行为 |
| 第二次仍展示 A，间隔配置 1/3 | 第二次后 A 需再满 72h；每日上限仍生效 |
| A/B 任意组合累计三次 | 永不再自动弹，后续行为不再记录 |
| 弹窗关闭、点击任一添加目标、跳转失败 | 均不撤销已发生的展示次数 |
| 设置 → 添加小组件 | 始终可进入，不增加任何频控次数 |
| 弹窗旋转/后台/频道切换 | 不重复计数，不恢复过期弹窗 |
| 重启 APP | 行为/次数保留；验证云配需重新开启 |
| 清除应用数据或重新安装 | 从零开始 |

## 迁移联调

- 真正的 ARouter 路由失败、singleTop/onNewIntent、多任务栈：适配层上报来源实例必须正确；本验证路由是 standard Activity。
- 对接已有弹窗管理器的占用/释放通知，验证其他弹窗期间不抢占、不延迟使用过期资格。
- 替换截图后在小屏、平板、横屏、深色模式、大字体上检查排版和两个按钮。
- 使用真实桌面/负一屏 deeplink 联调；本验证落地页仅验证参数。
- 冷启动、杀进程、磁盘失败：核对 pending 保守恢复，不把损坏状态当成首次安装。
- 设备修改系统时间/时区后，宿主应通知 refresh；纯本地频控不能提供可信服务端防篡改保证。
